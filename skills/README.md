# tufty.ai Agent Skills

Skills for publishing to ClawHub, one per tufty.ai studio tool. They are generated by `scripts/sync-skills.ts` from the tool manifest; do not edit them by hand.

Every skill drives the [`@tufty/cli`](https://www.npmjs.com/package/@tufty/cli) command-line tool:

```bash
npm install -g @tufty/cli@1.1.1
tufty login
```

| Skill | Display name | Type | What it does | Pricing |
| ----- | ------------ | ---- | ------------ | ------- |
| [tufty-pet-dressup](./tufty-pet-dressup) | 宠物换装 Pet Dress-Up | image | See any outfit on your pet — no photoshoot needed. | low 6 / medium 18 / high 49 / xhigh 71 / max 94 credits per image |
| [tufty-image-to-video](./tufty-image-to-video) | 图转视频 Image to Video | video | Animate any fashion image into a shareable short video. | 720P 19.05 credits per second |

All tools also charge 1 credit per input image for the automatic cutout (skip with `--no-cutout`). Prices come from the live manifest at generation time; `tufty tools describe <tool>` always shows the current ones.
